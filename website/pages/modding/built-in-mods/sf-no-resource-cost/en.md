# SF No Resource Cost

Removes resource consumption in supported building, crafting, and item-use actions.

## Package details

- Mod ID: `sf-no-resource-cost`
- Target processes: client and Dedicated Server
- Runtime capability: yes
- Declared player settings: 0

## Settings

This mod does not declare player-facing settings.

Settings are stored in the mod package's `extended.mod.json`. The mod reads them with `shroudforge.settings.get(key, fallback)`. See the [Lua source file](https://github.com/bonsaibauer/shroudforge/blob/HEAD/mods/sf-no-resource-cost/src/mod.lua) for implementation details.
