# SF Unlock Blueprints

Changes recipe unlock requirements to the first Flame Altar hint.

## Package details

- Mod ID: `sf-unlock-blueprints`
- Target processes: client and Dedicated Server
- Runtime capability: no
- Declared player settings: 0

## Settings

This mod does not declare player-facing settings.

Settings are stored in the mod package's `extended.mod.json`. The mod reads them with `shroudforge.settings.get(key, fallback)`. See the [Lua source file](https://github.com/bonsaibauer/shroudforge/blob/main/mods/sf-unlock-blueprints/src/mod.lua) for implementation details.
