# Eingebaute Mods und ihre Einstellungen

Diese Mods liegen im Repository unter `mods/`. Öffne eine Mod-Seite, um Zielprozesse, Zweck und Einstellungsgruppen zu sehen. Jede Einstellung besitzt eine eigene Seite mit Datentyp, Standardwert und erlaubten Werten. Mod-Einstellungen liegen in `extended.mod.json`, die allgemeinen Modloader-Einstellungen sind davon getrennt.

| Mod | Wirkung | Einstellungen |
| --- | --- | --- |
| [SF Auto Stamina Refill](#doc-builtin-mod-sf-auto-stamina-refill) | Füllt die Ausdauer wiederholt bis zum Maximum auf. | 1 Einstellungsseite |
| [SF Infinite Item Split](#doc-builtin-mod-sf-infinite-item-split) | Behält beim Teilen von Gegenständen den ursprünglichen Stapel. Das wirkt sich auch auf weitere Inventaraktionen aus. | keine spielerseitigen Einstellungen |
| [SF Infinite Item Use](#doc-builtin-mod-sf-infinite-item-use) | Verhindert, dass Gegenstände bei der Verwendung verbraucht werden. | keine spielerseitigen Einstellungen |
| [SF No Fall Damage](#doc-builtin-mod-sf-no-fall-damage) | Verhindert Lebenspunkteverlust durch Stürze. | keine spielerseitigen Einstellungen |
| [SF No Resource Cost](#doc-builtin-mod-sf-no-resource-cost) | Entfernt den Ressourcenverbrauch bei unterstützten Bau-, Herstellungs- und Verwendungsaktionen. | keine spielerseitigen Einstellungen |
| [SF Production Time](#doc-builtin-mod-sf-production-time) | Legt eine Basisdauer für zeitgesteuerte Produktionsrezepte fest. Weltgeschwindigkeitseinstellungen gelten weiterhin. | 1 Einstellungsseite |
| [SF Unlimited Flight](#doc-builtin-mod-sf-unlimited-flight) | Ermöglicht unbegrenztes Fliegen. | keine spielerseitigen Einstellungen |
| [SF Unlock Blueprints](#doc-builtin-mod-sf-unlock-blueprints) | Ändert die Freischaltbedingungen von Rezepten auf den ersten Hinweis am Flammenaltar. | keine spielerseitigen Einstellungen |
| [World Editor](#doc-builtin-mod-world-editor) | Weltbereiche kopieren, drehen, speichern und einfügen. | 37 Einstellungsseiten |
