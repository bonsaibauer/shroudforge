# SF Unlimited Flight

Lets you keep flying without a time limit.

## Package details

- Mod ID: `sf-unlimited-flight`
- Target processes: client and Dedicated Server
- Runtime capability: yes
- Declared player settings: 0

## Settings

This mod does not declare player-facing settings.

Settings are stored in the mod package's `extended.mod.json`. The mod reads them with `shroudforge.settings.get(key, fallback)`. See the [Lua source file](https://github.com/bonsaibauer/shroudforge/blob/main/mods/sf-unlimited-flight/src/mod.lua) for implementation details.
