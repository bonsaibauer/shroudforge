# SF Unlimited Flight

Ermöglicht unbegrenztes Fliegen.

## Paketangaben

- Mod-ID: `sf-unlimited-flight`
- Zielprozesse: Client und Dedicated Server
- Laufzeitberechtigung: ja
- Deklarierte spielerseitige Einstellungen: 0

## Einstellungen

Dieser Mod deklariert keine spielerseitigen Einstellungen.

Die Einstellungen werden in `extended.mod.json` des Mod-Pakets gespeichert. Der Mod liest sie über `shroudforge.settings.get(key, fallback)`. Weitere Details stehen in der [Lua-Quelldatei](https://github.com/bonsaibauer/shroudforge/blob/HEAD/mods/sf-unlimited-flight/src/mod.lua).
