# Template UUID high (hex)

Upper hexadecimal half of the native template UUID for the advanced Queue prop spawn action.

## Meaning and default

Copy, rotate, save, and paste parts of the world.

- Mod: World Editor (`world-editor`).
- Key read with `shroudforge.settings.get("templateUuidHigh", fallback)`: `templateUuidHigh`.
- Type: `string`.
- Starting value: `"0000000000000000"`.
- Text value. The mod package declares no additional length limit.
- The control is inferred from the value type.

## Source of this information

This page is based on `mods/world-editor/extended.mod.json`. Lua reads the current value with `shroudforge.settings.get("templateUuidHigh", fallback)`. Modloader saves player changes in the extension file. [Lua source file](https://github.com/bonsaibauer/shroudforge/blob/HEAD/mods/world-editor/src/mod.lua).
