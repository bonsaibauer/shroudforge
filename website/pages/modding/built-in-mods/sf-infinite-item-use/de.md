# SF Infinite Item Use

Verhindert, dass Gegenstände bei der Verwendung verbraucht werden.

## Paketangaben

- Mod-ID: `sf-infinite-item-use`
- Zielprozesse: Client und Dedicated Server
- Laufzeitberechtigung: ja
- Deklarierte spielerseitige Einstellungen: 0

## Einstellungen

Dieser Mod deklariert keine spielerseitigen Einstellungen.

Die Einstellungen werden in `extended.mod.json` des Mod-Pakets gespeichert. Der Mod liest sie über `shroudforge.settings.get(key, fallback)`. Weitere Details stehen in der [Lua-Quelldatei](https://github.com/bonsaibauer/shroudforge/blob/main/mods/sf-infinite-item-use/src/mod.lua).
