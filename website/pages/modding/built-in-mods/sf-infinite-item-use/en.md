# SF Infinite Item Use

Prevents items from being consumed when used.

## Package details

- Mod ID: `sf-infinite-item-use`
- Target processes: client and Dedicated Server
- Runtime capability: yes
- Declared player settings: 0

## Settings

This mod does not declare player-facing settings.

Settings are stored in the mod package's `extended.mod.json`. The mod reads them with `shroudforge.settings.get(key, fallback)`. See the [Lua source file](https://github.com/bonsaibauer/shroudforge/blob/main/mods/sf-infinite-item-use/src/mod.lua) for implementation details.
