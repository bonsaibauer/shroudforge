# SF Infinite Item Split

Keeps the original stack when splitting items. Also affects other inventory operations.

## Package details

- Mod ID: `sf-infinite-item-split`
- Target processes: client and Dedicated Server
- Runtime capability: yes
- Declared player settings: 0

## Settings

This mod does not declare player-facing settings.

Settings are stored in the mod package's `extended.mod.json`. The mod reads them with `shroudforge.settings.get(key, fallback)`. See the [Lua source file](https://github.com/bonsaibauer/shroudforge/blob/HEAD/mods/sf-infinite-item-split/src/mod.lua) for implementation details.
