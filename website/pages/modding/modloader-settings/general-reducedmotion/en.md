# Setting `general.reducedMotion`

Reduces motion and transition effects.

## What it changes

Reduces motion and transition effects.

## Default

`"nicht festgelegt"`





## Type and allowed values

Type: `boolean`.

No additional values or limits are declared by the schema.

## Configuration location

`shroudforge/config/modloader-config.json`, JSON path `/general/reducedMotion`. This configures the loader and is not copied into a mod package.

Source: `src/loader/package/src/config/loader.schema.json` and `loader.default.json`.
