# Steuerelement `color`

Für einen Farbwert, der im Modloader als Farbfeld bearbeitet wird. Lege es bei einer Einstellung als `control` fest.

```json
{
  "settings": {
    "example": {"value": "#d0ae6d", "label": "Farbauswahl", "control": "color"}
  }
}
```

Der Wert in `value` sollte zum Steuerelement passen. Weitere Regeln stehen unter [settings.<key>.control](#doc-field-settings-key-control).
