# Steuerelement `toggle`

Zeigt einen Ein/Aus-Schalter für einen booleschen Wert. Lege es bei einer Einstellung als `control` fest.

```json
{
  "settings": {
    "example": {"value": true, "label": "Schalter", "control": "toggle"}
  }
}
```

Der Wert in `value` sollte zum Steuerelement passen. Weitere Regeln stehen unter [settings.<key>.control](#doc-field-settings-key-control).
