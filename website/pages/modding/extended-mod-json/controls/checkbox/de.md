# Steuerelement `checkbox`

Zeigt einen booleschen Wert als Kontrollkästchen. Lege es bei einer Einstellung als `control` fest.

```json
{
  "settings": {
    "example": {"value": false, "label": "Kontrollkästchen", "control": "checkbox"}
  }
}
```

Der Wert in `value` sollte zum Steuerelement passen. Weitere Regeln stehen unter [settings.<key>.control](#doc-field-settings-key-control).
