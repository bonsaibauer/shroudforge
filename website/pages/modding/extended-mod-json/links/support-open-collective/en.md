# Link ID `support-open-collective`

Use this ID in `extended.mod.json → links.support-open-collective` and provide an HTTPS address. The Modloader displays the link with its registered icon and translated label.

```json
{
  "links": {
    "support-open-collective": "https://example.com/project"
  }
}
```

The IDs and their order are defined in [order.json](https://github.com/bonsaibauer/shroudforge/blob/HEAD/src/loader/modules/modloader-ui/ui/src/links/order.json).
