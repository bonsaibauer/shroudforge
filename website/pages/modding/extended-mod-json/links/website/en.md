# Link ID `website`

Use this ID in `extended.mod.json → links.website` and provide an HTTPS address. The Modloader displays the link with its registered icon and translated label.

```json
{
  "links": {
    "website": "https://example.com/project"
  }
}
```

The IDs and their order are defined in [order.json](https://github.com/bonsaibauer/shroudforge/blob/main/src/loader/modules/modloader-ui/ui/src/links/order.json).
