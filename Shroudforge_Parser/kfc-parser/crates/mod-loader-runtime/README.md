# mod-loader-runtime

## Purpose

`mod-loader-runtime` contains the legacy EML runtime-stage integration used after mods have been prepared by the shared loader layers.

## Current status

This crate is retained for the imported EML compatibility toolchain. Current ShroudForge runtime integration lives under `Shroudforge_Modloader/kfc-runtime` and `Shroudforge_API`.
