# mod-manager-gui

## Purpose

`mod-manager-gui` is the reserved graphical manager crate in the imported legacy EML workspace.

## Current status

The executable is not implemented. Its `main` function currently contains only a `todo!()` placeholder, so it must not be presented as a usable application.

Current ShroudForge graphical mod management is implemented by `Shroudforge_Modules/modloader-ui` in the repository root workspace.
