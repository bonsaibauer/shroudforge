Changelog:

- Add: Load Modloader Wiki pages and article summaries from the ShroudForge MediaWiki API. Search and article views follow the selected UI language, fall back to English (`en-GB`), and sanitize article HTML. Cache up to twelve recent searches and thirty articles, with a total size cap of 1.5 million characters, so cached content remains available when a request fails. The Wiki module is enabled by default with 30 results per page, up to 120 results per query, and a five-minute refresh interval. All four settings are configurable. Add Wiki help banners and links in the Modloader.
- Add: Provide a repeatable MediaWiki Translate workflow for ten article groups: Dependencies, DLL Manager, Engine, Game Profile Discovery, Hotkeys, Mod Detection, Modding, Modding Locales, Startup Asset Backups, and Translations. Include 120 PO translation files for the twelve supported target locales (`de-at`, `de-ch`, `de`, `es`, `fr`, `hi`, `it`, `ja`, `nl`, `pl`, `sv`, and `zh`), along with scripts to prepare translations, build page content and a publish manifest, publish missing pages and images without replacing existing article text, import PO files, and verify saved translations and rendered language pages.
- Add: Let a mod's own DLL register functions for the same mod's Lua code. A DLL loaded through `native-plugin.ini`, a DLL Manager selection, or `loader.runtime.register_dll` may export `ShroudforgeModNativeInit` (C header `modules/mod-runtime/native_bridge/shroudforge_mod_native.h`). Lua calls the registered functions with `shroudforge.native.call(name, ...)` and lists them with `shroudforge.native.functions()`. Arguments are nil, booleans, numbers, strings, and buffers, with strings and buffers passed without a copy. A mod reaches only its own functions, and the bridge grants no access to the game or to other mods. DLLs without the export load exactly as before.
- Add: Add the local player's state flags to reflected cursor snapshots as `value.playerStateMask`, read from the same local `ClientPlayerInput` as the cursor (`data.mask`, flag names such as `IsInMultiToolBuildingMenu`). A player who joined a game can now tell the building menu of the hammer, which `PlayerInput.fromClient.mask` holds only in the host's world.
- Update: Improve the download website with step-by-step ZIP extraction and game-folder installation guidance, a folder layout showing `dbghelp.dll`, `dinput8.dll`, `winmm.dll`, `shroudforge/`, and `mods/`, a copyable common Steam path (`C:\Program Files (x86)\Steam\steamapps\common\Enshrouded`), and a direct Wiki navigation link. Simplify the version selector by removing per-version release counts.
- Update: Select the latest listed release version by default in the download archive. Clearing search and channel filters returns to that version, while “All versions” is selected when there are no releases.
- Docs: Add a Linux, Wine/Proton, and Dedicated Server review and implementation plan covering the checked repository state, diagnosed issues, ownership boundaries, ordered work packages, and acceptance steps.
- Docs: Add official download-site and Modloader Wiki links with matching site-status badges to the README, then refine and simplify their placement.
- Update: Set the repository version to `1.8.0`.
