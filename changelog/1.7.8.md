- Add: Include runtime profiles for Enshrouded Hotfix #4 v1.0.1.1 that match client build `26404966` (`enshrouded.exe`) and Dedicated Server build `26404334` (`enshrouded_server.exe`) by executable identity.
- Fix: Make the runtime blocker and profile discovery banners dismiss consistently. A dismissal now applies only to the active banner and resets when its status changes. Record banner changes and dismissals in the UI log, and clarify the profile discovery notice color in the offline Wiki.
- Update: Improve autonomous beta profile discovery by following control-flow branches, returns, chained function ranges, and guarded dispatch tables. Prove indexed layouts from original arguments and matched registry factory ownership, reject ambiguous or mismatched evidence, and read the live system-normal count with its correct 16-bit width. Expand regression coverage for valid and invalid evidence paths.
- Update: Log each stage of dynamic game-profile discovery and selection, with clearer diagnostics and updated offline Wiki guidance.
- Docs: Add a MediaWiki migration package with localized ShroudForge Wiki articles, assets, page mappings, and an import builder.
- Update: Clearly mark asset mods that require a game restart in the Modloader compatibility page, navigation, and mod status.
- Fix: Read `mod.json`, `extended.mod.json` and the mod locale catalogs through a buffered reader. Unbuffered, serde_json read them one byte per system call: the hotkey check before saving a keybind took about 640 ms with a large mod installed (46 ms now), and the Modloader page of such a mod lagged.
- Fix: Prevent the Modloader window from scrolling when toggling switches in long settings lists.
- Add: Expose `shroudforge.clock()` to mods as a monotonic timer in seconds for measuring work and splitting time-budgeted tasks across updates.
- Update: Write the runtime heartbeat on its own thread so slow disk flushes do not stall mod updates, while keeping heartbeat freshness tied to the mods loop's last turn.
- Update: Keep the Debug Console responsive by sending only complete log lines added since the previous refresh and appending them in the UI. The UI keeps at most 2,000 displayed lines, and log reads and WebView rendering pause while the console is hidden.
- Add: Show a clear runtime compatibility banner at the top of F9 when runtime mods cannot work. Explain the cause and provide direct links to engine details, updates, and reporting. Include translations for all 14 supported languages.
- Fix: Recognize an exactly selected resource runtime profile before a world loads, so the main menu does not report working profiles as unsupported. Keep runtime compatibility errors, readiness, and banner status consistent.
- Add: Discover Enshrouded client and Dedicated Server builds from their exact running executables. Cache each supported normal build as the next update's comparison baseline, then create a persistent `beta_*` profile in the existing runtime profile catalog when the complete address and layout contract can be proven. No historical executable download is required. Unresolved evidence prevents publication of a partial profile.
- Update: Use one installed external JSON catalog for regular and generated runtime profiles instead of embedding profile data in `kfc-runtime.dll`. Exact normal profiles retain priority, automatic selection uses a verified beta profile when no exact normal profile exists, and client and server baselines remain separate. Steam build IDs label generated profiles when available, while executable identity remains authoritative.
- Add: Put the default-on dynamic profile setting beside runtime profile selection. Show the selected profile and an orange F9 notice while discovery runs or when a beta profile is active. Preserve the red runtime blocker for unresolved profile failures, and add localized status text plus offline Wiki guides.
- Add: Extend profile development tools with exact-image baseline selection and evidence-bound, non-production rebase candidates. Report changed and unresolved fields without treating static rankings as runtime approval.
