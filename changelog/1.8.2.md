Changelog:

- Update: Set the repository version to `1.8.2`.
- Update: Show protected hotkey rules in their own card and present engine compatibility checks in the same card layout as other Modloader settings.
- Update: Redesign the recycle bin as a responsive list with file counts, sizes, dates, and per-entry actions. Report restore, delete, and empty results through the shared command notifications. Shorten translated empty-state labels.
- Add: Move the local blueprint library into its own module with an installed tab. Import, rename, duplicate, delete, and manage covers for local blueprints, with World Editor access to the shared library.
- Update: Replace the line-based SFBP V7 format with UTF-8 JSON format 8 for World Editor blueprint import and export. Validate the document and blueprint-specific voxel and prop rules. Add the example and schema at `/schemas/sfbp/8/manifest.schema.json`. Earlier line-based files are not converted by renaming them.
- Update: Add a one-time migration that copies and verifies legacy blueprint files, covers, and previews from the former World Editor storage location into the local library. This moves files but does not convert their contents to SFBP 8.
- Update: Add contextual Wiki tab links to Modloader help panels. Show Wiki page controls in the top toolbar as well as below the list, and align the Mods, Discover, Updates, and recycle bin page headers.
- Update: Put system install or repair and uninstall actions in the Updates header. Show uninstall choices in a dialog that can be closed with Escape. Rename the installed-mod tab to Mods.
- Add: Integrate ShroudEdit Discover with tabs for Mods, Schematics, Modpacks, and Servers. Search, sort, filter, and paginate the catalog. Open project pages with descriptions, version tables, dependencies, and galleries, including an image viewer. Server projects can be browsed but not installed.
- Add: Install selected ShroudEdit mod and schematic versions through the updater. Check the selected project and version, download the package, and use the existing mod installation or Schematics library pipeline. Show a VirusTotal link beside a version when a suitable published file hash is available.
- Add: Introduce `.sfpack` format 1 for Enshrouded modpacks. Its `shroudforge.index.json` pins public ShroudEdit mod projects and versions with SHA-512 hashes. Validate the archive, catalog references, game compatibility, and required dependency closure. Download each pinned mod through the normal package pipeline, reject conflicting installed versions, and recycle newly installed packages if installation fails.
- Update: Check ShroudEdit for updates to catalog-installed mods and manually installed mods whose `mod.json.id` matches a project slug. Use the installed version, declared release channel, and game version to find applicable versions before offering or queuing an update.
- Add: Extend optional `extended.mod.json` metadata with an independent `releaseChannel`, supported `gameVersions`, and nine detailed environment choices in `targets`. Keep the existing Client and Server target arrays valid, derive process targets for the Modloader, and show the declared environment as a localized badge. The Discover environment filter retains its Client and Server choices.
- Update: Limit `mod.json.id` to 64 characters so it matches ShroudEdit project slugs. Add version 1.8.2 website schema snapshots for the mod manifest, extension, and mod locale catalog, plus the SFBP 8 and `.sfpack` 1 schemas.
- Update: Clarify ShroudEdit schematic installation wording and describe blueprints as being added to the local library. Limit catalog schematic downloads to 256 MiB.
- Fix: Reword VirusTotal status and button labels to avoid a ClamAV false positive in packaged Windows executables.
