# 📦 Enshrouded Mod Loader (EML) Ecosystem Directory

A curated reference list of community mods built on or compatible with the **Enshrouded Mod Loader (EML)** framework, as of **July 31, 2026**.

> 📌 **Disclaimer & Community Note:**  
> This directory is provided purely for informational and reference purposes to showcase the growing EML ecosystem. **Inclusion on this list does not constitute an endorsement, official verification, or safety guarantee of any individual mod.** 
> 
> * Always back up your save files (`<Steam>\userdata\<your_id>\1203620\remote`) before installing runtime mods or tweaking game values.
> * Please direct all bug reports, technical issues, and feature requests to the respective mod authors on their individual mod pages.
