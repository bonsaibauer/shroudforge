# Branding notes

The settings file keeps the Star Citizen layout and replaces its subject matter with ShroudForge content. It cannot change the skin palette.

The current documentation site uses a dark teal base with gold and cyan accents. A close match for the wiki is:

| Role | Colour |
| --- | --- |
| Background | #0b1316 |
| Gold accent | #d0ae6d |
| Light gold | #eed49a |
| Cyan links | #71d0e6 |

Use these in the skin's existing LESS or CSS variables if you want the homepage to match the ShroudForge brand. The PNG logo included in assets is optional. No SVG upload support is required.
