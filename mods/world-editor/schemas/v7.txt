ShroudForge World Editor blueprint format: SFBP V7
==================================================

Extension: .sfbp
Version marker: SHROUDFORGE_WORLD_BLUEPRINT_V7
Reference implementation: mods/world-editor/src/sfbp_v7.lua

The World Editor uses this Lua implementation to validate and decode loaded
blueprints. It also checks the current prop limit and placement recipes, which
depend on the active configuration and game. The executable implementation is
published alongside this document at /schemas/sfbp/v7.lua.

SFBP V7 is a line-based text format, not JSON. The World Editor writes
lines separated by LF (U+000A), with no trailing LF after the final line.
Use this exact line ending and do not add a byte order mark. Commas separate
fields within a line. The file contains ten header lines followed by exactly
the number of prop lines declared on line 10. Numeric fields must be finite.

Header lines
------------
 1  SHROUDFORGE_WORLD_BLUEPRINT_V7
 2  Rotation axis: x, y or z.
 3  Selection extent in world units: extentX,extentY,extentZ. Each value is
    nonnegative. All three must be positive for a props-only blueprint.
 4  Channel kind: voxel or props.
 5  Voxel dimensions: sizeX,sizeY,sizeZ, or - for props-only.
 6  Voxel channel offset from the selection anchor in world units:
    offsetX,offsetY,offsetZ, or - for props-only.
 7  Voxel cell size in world units: cellSizeX,cellSizeY,cellSizeZ, or - for
    props-only. Each cell size must be positive.
 8  Comma-separated voxel values, or - for props-only.
 9  Comma-separated voxel coverage values, or - for props-only.
10  Number of props as a nonnegative integer.

Voxel channel
-------------
Dimensions are positive integers and their product must not exceed 65,536.
Lines 8 and 9 each contain exactly sizeX * sizeY * sizeZ entries. The X
coordinate varies fastest, then Y, then Z. The zero-based index is
x + sizeX * (y + sizeY * z).

Voxel values are integers from 0 through 65,535. Coverage values mean:
  0  Unknown. Preserve the target cell when pasting.
  1  Empty. Clear the target in replace mode, skip it in additive mode.
  2  Occupied. The corresponding voxel value must be nonzero.
On load, the reader sets values with coverage 0 or 1 to zero.

Prop lines
----------
Each prop occupies one line with exactly 13 comma-separated fields:

itemId,x,y,z,qx,qy,qz,qw,scaleX,scaleY,scaleZ,templateHighHex,templateLowHex

itemId is a positive integer with a placement recipe available in the current
game. x, y and z are offsets from the blueprint anchor in world units. The
rotation is a quaternion in x, y, z, w order. Its squared norm must be finite
and at least 1e-12. Scale has one finite value per axis and may be nonuniform.
The two template fields are hexadecimal strings of 1 to 16 digits each,
representing the high and low 64-bit halves of the native entity-template UUID.
They cannot both be zero. Preserve them as strings or exact integers, never as
floating-point numbers. The reader accepts uppercase and lowercase hex digits.

The prop count cannot exceed the configured Maximum props per blueprint or
the implementation maximum of 1,000,000. The default configured limit is
60,000. Local blueprint files are limited to 256 MiB. Online transfer has a
separate 32 MiB limit. Placement also depends on the active world and runtime,
including voxel grid alignment and availability of the required operations.

Example with voxels and one prop
-------------------------------
The following is the content of one file, without a final newline:

SHROUDFORGE_WORLD_BLUEPRINT_V7
y
1,0.5,1.5
voxel
2,1,3
-0.5,0,0.5
0.5,0.5,0.5
10,20,0,40,0,60
2,2,1,2,0,2
1
42,0.25,0.5,0.75,0,0,0,1,0.5,1.25,2,fedcba9876543210,0123456789abcdef

Example with props only
-----------------------
The following is the content of one file, without a final newline:

SHROUDFORGE_WORLD_BLUEPRINT_V7
y
1,1,1
props
-
-
-
-
-
0

Examples illustrate the wire format. Loading a prop requires its item to have
a current placement recipe. This specification describes V7 and does not
claim compatibility with other format versions.
